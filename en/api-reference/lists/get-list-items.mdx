## Usage

Returns the items in a list with pagination.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/lists/LIST_ID/items?page=1&pageSize=20"
```
