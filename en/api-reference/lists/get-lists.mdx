## Usage

Returns the lists accessible to the authenticated user, with pagination.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/lists?page=1&pageSize=20"
```
