## Usage

Returns the information required to display the QR code for a device. This operation is public.

No API key is required.

The required `user_code` query parameter is defined by the OpenAPI contract.

## Example

```bash
curl "https://dejavu.plus/api/v1/auth/device/qr?user_code=USER_CODE"
```

## Parameters and response

The request parameters and responses are defined by the OpenAPI specification displayed on this page.

## Errors

See **Responses** for the operation-specific error codes and formats.

## Notes

Do not expose device codes or access tokens in public source code or logs.
