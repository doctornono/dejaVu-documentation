## Usage

Starts the device authentication flow. This operation is public.

No API key is required.

## Example

```bash
curl -X POST -H "Content-Type: application/json" "https://dejavu.plus/api/v1/auth/device/code"
```

## Parameters and response

The request body, parameters, and responses are defined by the OpenAPI specification displayed on this page.

## Errors

See **Responses** for the operation-specific error codes and formats.

## Notes

The device code is intended for clients such as Kodi extensions and other living-room applications.
