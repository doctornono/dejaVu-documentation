## Usage

Exchanges an approved device code for an access token. This operation is public.

No API key is required.

## Example

```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"device_code":"DEVICE_CODE","grant_type":"urn:ietf:params:oauth:grant-type:device_code"}' \
  "https://dejavu.plus/api/v1/auth/device/token"
```
