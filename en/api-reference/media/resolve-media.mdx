## Usage

Resolves a media item from the identifiers or metadata supplied in the request.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" \
  -d '{"tmdbId":550,"type":"movie"}' "https://dejavu.plus/api/v1/media/resolve"
```
