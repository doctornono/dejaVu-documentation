## Usage

Returns the dejaVu status of multiple media items in a single request.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" \
  -d '{"items":[{"type":"movie","id":550}]}' "https://dejavu.plus/api/v1/media/status"
```
