## Usage

Returns the authenticated user's dashboard widget configuration.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/dashboard"
```

The response schema is defined by the OpenAPI specification displayed on this page. This operation does not require query parameters.
