## Usage

Returns the details of a channel and the lists associated with it.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/channels/CHANNEL_ID"
```
