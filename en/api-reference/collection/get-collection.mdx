## Usage

Returns the authenticated user's collection with optional pagination and filters.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/collection?page=1&pageSize=20"
```

## Notes

Use pagination for large collections. Never expose an `sk_` key in client-side code or a public repository.
