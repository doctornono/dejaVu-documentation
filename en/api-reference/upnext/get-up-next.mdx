## Usage

Returns the next episodes to watch for the user's followed series, with pagination.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/upnext?page=1&pageSize=20"
```

## Parameters and response

Query parameters and response schemas are defined by the OpenAPI specification displayed on this page.

## Errors

See **Responses** for the operation-specific error codes and formats.

## Notes

Pagination uses `page` and `pageSize`; the obsolete `limit` parameter is not part of the v1 contract.
