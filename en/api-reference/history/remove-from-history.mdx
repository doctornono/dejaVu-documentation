## Usage

Removes a watch entry from the authenticated user's history.

Authentication is required via `x-api-key` or `Authorization: Bearer`. Write access requires the permissions associated with a secret key (`sk_`).

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/history?type=movie&id=550"
```

## Notes
