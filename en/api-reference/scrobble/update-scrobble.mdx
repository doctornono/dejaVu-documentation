## Usage

Creates or updates a playback session and its progress.

Authentication is required via `x-api-key` or `Authorization: Bearer`. Write access requires the permissions associated with a secret key (`sk_`).

## Example

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" \
  -d '{"type":"movie","id":550,"progress":50}' "https://dejavu.plus/api/v1/scrobble"
```

## Parameters and response

The request body and responses are defined by the OpenAPI specification displayed on this page.

## Errors

See **Responses** for the operation-specific error codes and formats.

## Notes

At a playback progress of at least 90%, dejaVu applies the completion behavior documented by the API.
