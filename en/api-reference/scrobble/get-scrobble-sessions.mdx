## Usage

Returns the authenticated user's active playback sessions.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/scrobble?page=1&pageSize=20"
```
