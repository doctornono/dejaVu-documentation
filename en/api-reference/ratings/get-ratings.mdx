## Usage

Returns the authenticated user's ratings with pagination.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/ratings?page=1&pageSize=20"
```

## Parameters and response

Query parameters and response schemas are defined by the OpenAPI specification displayed on this page. Ratings can apply to movies, TV shows, seasons, or episodes depending on the supplied context.
