## Utilisation

Retourne les notes paginées de l’utilisateur authentifié.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/ratings?page=1&pageSize=20"
```

## Paramètres et réponse

Les paramètres et schémas de réponse sont définis par la spécification OpenAPI affichée sur cette page. Les notes peuvent concerner des films, séries, saisons ou épisodes selon le contexte fourni.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.
