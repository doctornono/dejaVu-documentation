## Utilisation

Associe et approuve un appareil à partir du flux d’autorisation DejaVu.

Aucune clé API n’est requise pour cette opération.

## Exemple

```bash
curl -X POST -H "Content-Type: application/json" "https://dejavu.plus/api/v1/auth/device/approve"
```
