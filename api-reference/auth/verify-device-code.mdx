## Utilisation

Vérifie l’état d’un code utilisateur. Cette opération est publique.

Aucune clé API n’est requise pour cette opération.

## Exemple

```bash
curl -X GET -H "Content-Type: application/json" "https://dejavu.plus/api/v1/auth/device/verify"
```
