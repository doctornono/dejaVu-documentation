## Utilisation

Crée ou met à jour une session de lecture et sa progression.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/scrobble"
```

## Paramètres et réponse

Les paramètres, schémas de requête et réponses sont définis par la spécification OpenAPI affichée sur cette page. Utilisez les champs du schéma pour construire la requête.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération. Une réponse `401` indique une authentification absente ou invalide.

## Notes

À partir d’une progression d’au moins 90 %, DejaVu applique le comportement de complétion documenté par l’API.
