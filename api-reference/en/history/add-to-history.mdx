## Usage

Adds a watch entry to the authenticated user's history.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/history"
```
