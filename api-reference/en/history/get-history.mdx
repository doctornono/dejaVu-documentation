## Usage

Retourne l’historique de visionnage paginé de l’utilisateur authentifié.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/history?page=1&pageSize=20"
```

## Parameters and response

Les paramètres de pagination, filtres éventuels et schémas de réponse sont définis par la spécification OpenAPI affichée sur cette page.
