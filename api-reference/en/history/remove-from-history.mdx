## Usage

Remove une entrée de l’history de the authenticated user.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/history"
```
