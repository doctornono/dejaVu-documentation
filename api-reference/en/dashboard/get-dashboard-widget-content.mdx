## Usage

Returns the requested content for a dashboard widget.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/dashboard/widget?type=up_next&page=1&pageSize=20"
```

## Parameters and response

The `type`, optional `listId`, pagination, and `minimal` parameters are defined by the OpenAPI specification displayed on this page.
