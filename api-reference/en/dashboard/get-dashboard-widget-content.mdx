## Usage

Retourne le content demandé pour un widget du dashboard.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X GET -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/dashboard/widget?page=1&pageSize=20"
```
