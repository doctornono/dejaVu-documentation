## Usage

Removes a movie or TV show from the authenticated user's collection.

Authentication is required via `x-api-key` or `Authorization: Bearer`. Write access requires the permissions associated with a secret key (`sk_`).

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/collection?type=movie&id=550"
```
