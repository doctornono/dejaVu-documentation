## Usage

Liste la collection de l’utilisateur authentifié. La réponse est paginée.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/collection?page=1&pageSize=20"
```

## Parameters and response

Parameters, schemas, and responses are defined by the OpenAPI specification displayed on this page.

## Errors

See **Responses** for the operation-specific error codes and formats. A `401` response indicates missing or invalid authentication.

## Notes

Utilisez la pagination pour les collections volumineuses. Never expose an `sk_` API key in client-side code or a public repository.
