## Usage

Démarre un flux d’authentification par appareil. Cette opération est publique.

Aucune clé API n’est requise pour cette opération.

## Example

```bash
curl -X POST -H "Content-Type: application/json" "https://dejavu.plus/api/v1/auth/device/code"
```
