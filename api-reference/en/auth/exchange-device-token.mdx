## Usage

Échange un device code approuvé contre un jeton. Cette opération est publique.

Aucune clé API n’est requise pour cette opération.

## Example

```bash
curl -X POST -H "Content-Type: application/json" "https://dejavu.plus/api/v1/auth/device/token"
```

## Parameters and response

Les paramètres, schémas de requête et réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Errors

See **Responses** for the operation-specific error codes and formats.

## Notes

Le flux utilise `grant_type=urn:ietf:params:oauth:grant-type:device_code`.
