## Usage

Retourne les informations nécessaires à l’affichage du QR code d’un appareil. Cette opération est publique.

Aucune clé API n’est requise pour cette opération.

## Example

```bash
curl -X GET -H "Content-Type: application/json" "https://dejavu.plus/api/v1/auth/device/qr"
```
