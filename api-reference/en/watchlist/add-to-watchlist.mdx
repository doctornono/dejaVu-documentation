## Usage

Adds a media item to the authenticated user's watchlist.

Authentication is required via `x-api-key` or `Authorization: Bearer`. Write access requires the permissions associated with a secret key (`sk_`).

## Example

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" \
  -d '{"type":"movie","id":550}' "https://dejavu.plus/api/v1/watchlist"
```
