## Usage

Retourne le profile de l’user authenticated et ses informations statistiques exposées par l’API.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X GET -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/me?page=1&pageSize=20"
```
