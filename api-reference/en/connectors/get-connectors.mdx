## Usage

Retourne les connectors approuvés disponibles pour l’intégration.

Aucune clé API n’est requise pour cette opération.

## Example

```bash
curl -X GET -H "Content-Type: application/json" "https://dejavu.plus/api/v1/connectors"
```
