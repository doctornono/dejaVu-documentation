## Usage

Retourne les sessions de lecture actives de l’utilisateur.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X GET -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/scrobble?page=1&pageSize=20"
```

## Errors
