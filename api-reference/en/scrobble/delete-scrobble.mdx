## Usage

Removes une playback session active.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/scrobble"
```
