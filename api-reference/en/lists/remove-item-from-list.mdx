## Usage

Removes an item from a list. The item identifier is supplied through the query parameter `id`, in addition to the list path parameter.

Authentication is required via `x-api-key` or `Authorization: Bearer`. Write access requires the permissions associated with a secret key (`sk_`).

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/lists/LIST_ID/items?id=ITEM_ID&type=movie"
```
