## Usage

Retire un élément d’une liste. L’identifiant d’élément utilise le paramètre `id`.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/lists/{id}/items"
```
