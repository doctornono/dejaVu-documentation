## Usage

Remove une rating existante. Pour une saison ou un episode, utilisez le contexte correspondant.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/ratings"
```
