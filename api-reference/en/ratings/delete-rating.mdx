## Usage

Deletes an existing rating. For a season or episode, provide the corresponding context.

Authentication is required via `x-api-key` or `Authorization: Bearer`. Write access requires the permissions associated with a secret key (`sk_`).

## Example

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/ratings?type=movie&id=550"
```
