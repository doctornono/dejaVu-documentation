## Usage

Crée ou met à jour la rating d’un movie, d’une series, d’une saison ou d’un episode selon le contexte fourni.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/ratings"
```

## Parameters and response

Request parameters, schemas, and responses are defined by the OpenAPI specification displayed on this page. Use the schema fields to build the request.

## Errors

See **Responses** for the operation-specific error codes and formats. Une réponse `401` indique une authentification absente ou invalide.
