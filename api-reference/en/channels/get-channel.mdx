## Usage

Retourne le détail d’une chaîne publique et les listes qui lui sont associées.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -X GET -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/channels/{id}"
```
