## Usage

Retourne les chaînes publiques disponibles.

Cette opération est publique.

## Example

```bash
curl -X GET -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/channels?page=1&pageSize=20"
```
