## Usage

Returns the public channels available to the authenticated user.

Authentication is required via `x-api-key` or `Authorization: Bearer`.

## Example

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/channels?page=1&pageSize=20"
```
