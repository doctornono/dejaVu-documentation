## Utilisation

Retire un média de la collection.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/collection"
```

## Paramètres et réponse

Les paramètres, schémas de requête et réponses sont définis par la spécification OpenAPI affichée sur cette page. Pour les requêtes d’écriture, envoyez le corps JSON conforme au schéma indiqué.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération. Une réponse `401` indique une authentification absente ou invalide.

## Notes

- N’exposez jamais une clé API `sk_` dans du code client ou un dépôt public.
- Utilisez la pagination pour les collections volumineuses.
