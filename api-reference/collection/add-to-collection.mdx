## Utilisation

Ajoute un média à la collection de l’utilisateur authentifié.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/collection"
```

## Paramètres et réponse

Les paramètres, schémas et réponses sont définis par la spécification OpenAPI affichée sur cette page. Envoyez un corps JSON conforme au schéma indiqué.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.

## Notes

Pour les épisodes, utilisez le contexte de série, saison et épisode prévu par le schéma. N’exposez jamais une clé API `sk_` dans du code client ou un dépôt public.
