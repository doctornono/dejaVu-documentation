## Utilisation

Retourne les listes accessibles à l’utilisateur, avec pagination.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X GET -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/lists?page=1&pageSize=20"
```
