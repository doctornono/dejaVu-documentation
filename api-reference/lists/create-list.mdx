## Utilisation

Crée une nouvelle liste selon les paramètres de visibilité et de type définis par l’API.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/lists"
```

## Paramètres et réponse

Les paramètres, schémas de requête et réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.
