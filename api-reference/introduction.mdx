# Référence API v1

Cette section est la référence technique de l’API DejaVu. Les endpoints sont décrits à partir de `api-reference/openapi.json`.

## Authentification

La majorité des endpoints utilisent une clé API dans l’en-tête `x-api-key` ou un jeton Bearer dans `Authorization`.

```http
x-api-key: pk_VOTRE_CLE
```

ou :

```http
Authorization: Bearer VOTRE_CLE
```

Les clés API ne doivent pas être placées dans l’URL. La forme `?api_key=` n’est pas supportée.

## Convention de réponse

Les endpoints qui utilisent l’enveloppe standard renvoient un objet contenant notamment `success` et, selon l’opération, `data`, `pagination` ou `user`.

Les codes HTTP restent la source de vérité pour déterminer si une requête a réussi.

## Playground

La référence OpenAPI fournit un playground interactif lorsque l’endpoint est compatible avec celui-ci. Il permet de renseigner l’authentification, les paramètres et le corps de requête puis d’observer la réponse réelle.

Pour les tests avancés propres à DejaVu, notamment les scénarios nécessitant un contexte utilisateur ou des opérations internes, utilisez également le playground administrateur disponible dans DejaVu.

<Warning>
Ne partagez jamais une clé `sk_` dans une application cliente ou dans du code distribué publiquement.
</Warning>
