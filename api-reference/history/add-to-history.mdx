## Utilisation

Ajoute un visionnage à l’historique de l’utilisateur authentifié.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X POST -H "x-api-key: $DEJAVU_API_KEY" -H "Content-Type: application/json" "https://dejavu.plus/api/v1/history"
```

## Paramètres et réponse

Le corps JSON et les réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.

## Notes

Pour un épisode, renseignez le contexte de série, saison et épisode lorsque requis. La date de visionnage peut être transmise selon le schéma de requête.
