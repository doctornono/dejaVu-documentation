# DejaVu API v1

L’API v1 permet aux applications, extensions et intégrations de lire et de modifier les données personnelles d’un compte DejaVu.

<Note>
La référence technique est générée à partir de la spécification OpenAPI. Les exemples et guides complètent cette référence avec des explications pratiques.
</Note>

## Pour commencer

1. Créez ou récupérez une clé API DejaVu.
2. Ajoutez-la à vos requêtes avec l’en-tête `x-api-key` ou `Authorization: Bearer`.
3. Testez votre première requête dans le playground de la référence API.
4. Consultez les endpoints par ressource lorsque vous commencez votre intégration.

## Authentification

Les clés API sont transmises dans les en-têtes HTTP. Les clés dans la query string (`?api_key=`) ne sont pas supportées.

```bash
curl https://dejavu.plus/api/v1/me \
  -H "x-api-key: pk_VOTRE_CLE"
```

Une clé publique `pk_` est destinée aux opérations de lecture. Une clé secrète `sk_` permet les opérations de lecture et d’écriture lorsque l’endpoint l’autorise.

## Ressources

La référence couvre les collections, historiques, favoris, notes, watchlist, scrobble, listes, dashboard, médias, channels, connecteurs, import Kodi et Device Flow.
