## Utilisation

Vérifie l’état d’un code utilisateur. Cette opération est publique.

Aucune clé API n’est requise.

Le paramètre de requête obligatoire `user_code` est défini par le contrat OpenAPI.

## Exemple

```bash
curl "https://dejavu.plus/api/v1/auth/device/verify?user_code=CODE_UTILISATEUR"
```

## Paramètres et réponse

Les paramètres de requête et les réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.
