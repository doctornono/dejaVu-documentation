## Utilisation

Approuve une demande d’autorisation d’appareil pour l’utilisateur dejaVu actuellement connecté.

Cette opération nécessite une session dejaVu authentifiée. Elle n’utilise pas de clé API.

## Exemple

```bash
curl -X POST -H "Content-Type: application/json" \
  -H "Cookie: <SESSION_DEJAVU>" \
  -d '{"user_code":"CODE_UTILISATEUR"}' \
  "https://dejavu.plus/api/v1/auth/device/approve"
```

## Paramètres et réponse

Le corps de requête et les réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.

## Notes

L’approbation est effectuée dans la session utilisateur dejaVu authentifiée.
