## Utilisation

Retourne les chaînes publiques accessibles à l’utilisateur authentifié.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/channels?page=1&pageSize=20"
```

## Paramètres et réponse

Les paramètres de pagination et de filtrage, ainsi que le schéma de réponse, sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.
