## Utilisation

Retourne le détail d’une chaîne et les listes qui lui sont associées.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/channels/CHANNEL_ID"
```

## Paramètres et réponse

L’identifiant de la chaîne et le schéma de réponse sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.
