## Utilisation

Retourne le profil de l’utilisateur authentifié et les statistiques exposées par l’API.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/me"
```

## Paramètres et réponse

Le schéma de réponse est défini par la spécification OpenAPI affichée sur cette page. Cette opération n’accepte pas de paramètre de requête.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.
