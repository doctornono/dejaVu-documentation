## Utilisation

Retire un média de la collection de l’utilisateur authentifié.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -X DELETE -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/collection"
```

## Paramètres et réponse

Les paramètres et réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération.

## Notes

Vérifiez le type et l’identifiant du média avant suppression. Pour les épisodes, respectez le contexte prévu par le schéma.
