## Utilisation

Liste la collection de l’utilisateur authentifié. La réponse est paginée.

L’authentification est requise via `x-api-key` ou `Authorization: Bearer`.

## Exemple

```bash
curl -H "x-api-key: $DEJAVU_API_KEY" "https://dejavu.plus/api/v1/collection?page=1&pageSize=20"
```

## Paramètres et réponse

Les paramètres, schémas et réponses sont définis par la spécification OpenAPI affichée sur cette page.

## Erreurs

Consultez **Responses** pour les codes et formats d’erreur propres à l’opération. Une réponse `401` indique une authentification absente ou invalide.

## Notes

Utilisez la pagination pour les collections volumineuses. N’exposez jamais une clé API `sk_` dans du code client ou un dépôt public.
